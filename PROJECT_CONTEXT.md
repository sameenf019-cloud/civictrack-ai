# CivicTrack AI - Project Context

## What it is
Civic issue reporting platform. Citizens report problems (potholes,
garbage, water leakage, broken streetlights) with photo and location.
Admin reviews and assigns. Officer resolves with evidence. Citizen
tracks progress. Public sees a privacy-safe map.

## Goal
Working prototype (not an FYP). Small steps, real functionality, no fake
results.

## Roles
citizen, admin, officer, public visitor

## Tech stack (prototype)
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy, Pydantic
- Database: SQLite now, PostgreSQL later
- Maps: Leaflet, OpenStreetMap
- Auth: JWT, password hashing with Argon2 or bcrypt
