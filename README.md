# CivicTrack AI

Report. Detect. Prioritize. Resolve.

A civic issue reporting platform where citizens report infrastructure
problems, admins assign them, and officers resolve them with evidence.

## Status

Work in progress (prototype).

## Planned Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy
- Database: SQLite (prototype), PostgreSQL later
- Maps: Leaflet, OpenStreetMap
